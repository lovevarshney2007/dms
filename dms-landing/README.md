# DMS Aarohi - Main Portal Landing Page

This is the primary entry point for `dmsaarohi.com`. It serves as a beautifully designed, high-performance landing page that routes visitors to either the **Talent Hunt** platform or the **NGO** website.

## Features
- Dynamic cursor spotlight and animated backgrounds.
- Direct links to the Talent Hunt and NGO platforms.
- Admin Login button to access the unified administrative console.

## Running Locally
```bash
npm install
npm run dev
```
