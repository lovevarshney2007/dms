# DMS Aarohi - Unified Admin Panel

This React application serves as the centralized administrative portal for the entire DMS Aarohi ecosystem.

## Features

- **Portal Hub**: The main dashboard provides high-level statistics and acts as a gateway to specialized admin consoles.
- **Talent Hunt Console**: For managing talent registrations, events, seasons, sponsors, and success stories.
- **NGO Console**: A dedicated standalone console for managing NGO volunteers, team members, blood donors, and gallery images filtered by initiative.

## Running Locally
```bash
npm install
npm run dev
```

## Environment Variables
Create a `.env` file with:
```env
VITE_API_BASE=http://localhost:5051/api
```
