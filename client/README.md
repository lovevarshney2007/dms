# DMS Aarohi - Talent Hunt Platform

This is the React frontend for the Talent Hunt initiative. It allows users to view upcoming events, success stories, and register for the latest talent show seasons.

## Architecture

This frontend is purely for the Talent Hunt side of the organization and connects to the unified backend API.

## Running Locally
```bash
npm install
npm run dev
```

## Environment Variables
Create a `.env` file with:
```env
VITE_API_BASE=http://localhost:5051/api
```
